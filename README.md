# Linked List Management System

## Objective
The objective of this project is to implement a menu-driven Linked List Management System using Java. It demonstrates the implementation and manipulation of both singly and doubly linked lists through various operations.

## Language Used
- Java

## Features
- Menu-driven console interface
- Implementation of a Singly Linked List
- Implementation of a Doubly Linked List
- Insertion and deletion of nodes
- Searching and updating node values
- Displaying linked list elements
- Counting the number of nodes
- Finding the maximum and minimum values
- Finding the middle node
- Reversing a linked list
- Sorting and removing duplicate elements *(pending implementation)*

## Singly Linked List
A singly linked list is a linear data structure in which each node contains data and a reference to the next node.

### Operations
1. Insert at Beginning
2. Insert at End
3. Insert at Position
4. Insert After a Node
5. Insert Before a Node
6. Delete from Beginning
7. Delete from End
8. Delete from Position
9. Delete by Value
10. Search
11. Update
12. Display
13. Count Nodes
14. Find Maximum
15. Find Minimum
16. Find Middle Node
17. Reverse
18. Sort *(pending implementation)*
19. Remove Duplicates *(pending implementation)*

## Doubly Linked List
A doubly linked list is a linear data structure in which each node contains data and references to both the previous and the next nodes.

### Operations
1. Insert at Beginning
2. Insert at End
3. Insert at Position
4. Insert After a Node
5. Insert Before a Node
6. Delete from Beginning
7. Delete from End
8. Delete from Position
9. Delete by Value
10. Search
11. Update
12. Display Forward
13. Display Backwards
14. Count Nodes
15. Find Maximum
16. Find Minimum
17. Find Middle Node
18. Reverse
19. Sort *(pending implementation)*
20. Remove Duplicates *(pending implementation)*

## How to Run
1. Open Eclipse IDE.
2. Import or open the Java project.
3. Ensure all Java source files are in the `src` folder.
4. Open `Main.java`.
5. Run the program as a Java Application.
6. Follow the menu options displayed in the console.
